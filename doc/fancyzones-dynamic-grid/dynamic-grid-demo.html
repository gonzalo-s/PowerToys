FancyZones dynamic grid: design demo

Drag the edge or corner of any window. The divider line moves, neighbors follow live, nothing overlaps. Drag it back near the dashed line and it snaps to the original position.

Demo only: HTML model of the planned behavior, not PowerToys code.

Rules shown: whole divider line moves; zones are clamped to a minimum size; edges on the work-area border do nothing; a window spanning several zones can only move dividers on its outer sides; when every divider equals its base value, the working layout disappears.
